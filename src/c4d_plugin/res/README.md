# `res` — Cinema 4D resource files

Cinema 4D plugin **description resources**: parameter layouts (`.res`), symbol
headers, and localized strings (`strings_xx/`). These define the tags' and
controller's user-facing parameters (speed of light, velocities, time mode,
effect toggles).

This format is shared with the Cinema 4D **C++ SDK**, so resources written here
carry over to a future C++ migration unchanged.
